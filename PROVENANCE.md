# MCP provenance

MCP 0.0.1 starts a new public repository history. Its implementation derives from the generic MCP source in DearAgent commit `bbad6c32f332c371423f0f2d7e9852b672862c67`, directory `external/kit/`, followed by independent MCP development. Historical Git objects, build products, research work, credentials and personal configuration are not included in the public source export. A fresh history does not remove the attribution below.

Runtime source resides in `src/mcp/`; the public interface is now `include/mcp/`, namespace `mcp`, umbrella header `mcp/all.h`, and CMake target `MCP::MCP`. This is the initial public interface, not a promise to preserve the private extraction's C++ names. Wire identifiers remain those of the official protocol. The stdio launcher and CLI inspector use Boost.Process V2 and standard filesystem paths, with native process-tree ownership and launch regression tests. Additional corrections unify task validation, preserve the total task-call budget and filter invalid HTTP tool annotations independently. Source/final hashes and path mappings are recorded in the source manifest. Tests, fixtures, CLI and examples are retained; runtime deployment and license helpers derive from Kit's existing helper closure.

Kit was originally imported from `02b3004d70df2824762364313d9213768a11d09e`. Native MCP historical source: UniMCP `b450b822ff5dff2d524d3b24b2147e7eb2cf1413`; cpp-mcp upstream reference `13a8bef` (https://github.com/hkr04/cpp-mcp). MIT attribution is retained in `licenses/mcp.txt` and `NOTICE`. Schema fixture provenance and license are in `NOTICE` and `tests/mcp/fixtures/licenses/MCP-LICENSE`.

Official UniMemory fallback is unmodified pinned source `3dbe431a6c9a4bb5cf0aebd9e472baebfd96f925` from https://github.com/dugan-dev/UniMemory. Its exact inventory/hashes are in `external/unimemory/snapshot.json` and its MIT license remains in that directory. A host target or installed package may supply the same compatible fixed profile; this project does not create a second UniMemory target when one already exists.

Historical Kit documentation is reference material, not this project's verification record. Standalone verification scope is recorded in `docs/validation.md`. Runtime dependency redistributors must retain dependency licenses; the Windows install helper collects the configured dependency notices. The source package contains no dependency binaries. The localhost test key is an intentionally public fixture.

The project-local `ports/boost-process` profile derives from vcpkg baseline `2f1d605400c8727cc00c15797aba796c88ccd523`, retaining its Boost 1.91.0 source archive hash, original patch and licenses. It enables upstream `BOOST_PROCESS_USE_STD_FS`; an additional CMake-only comment patch uses the BoostRoot scanner's supported `Boost-Exclude` directive for the inactive Filesystem branch. Boost implementation sources remain unmodified. See the [overlay notes](ports/boost-process/README.md).
