# Security reports

Do not post credentials, private application data or unpublished exploit details
in public issues or pull requests.

If GitHub displays **Report a vulnerability** for this repository, use its
[private report form](https://github.com/dugan-dev/MCP/security/advisories/new).
If the form is unavailable, open an issue requesting a private contact route
without describing the vulnerability or attaching a reproducer. Availability of
GitHub's private reporting feature depends on the repository configuration.

Include the affected commit and version, OS/compiler, dependency versions,
transport, build options, smallest synthetic reproducer and demonstrated impact.
Distinguish a confirmed defect from an unverified concern. Avoid secrets and
unrelated application data in logs or network captures.

The `0.0.1` version alone does not identify a source revision. Include the full
commit when reporting an issue or checking a fix. No response-time, long-term
support or backport schedule is promised. Coordinate disclosure of technical
details and fixes through the private route.
