# Changelog

## 0.0.1

- Initial public C++20 MCP library with `<mcp/all.h>`, namespace `mcp` and `MCP::MCP`.
- Client/server, stdio, HTTP/TLS/SSE, tools, resources, prompts, validation and optional extensions for protocol 2026-07-28.
- Boost.Process V2 with `std::filesystem`, Unicode launch options and owned process-tree cleanup.
- Exception-safe subprocess startup and shutdown, including allocation failure and pending-request wakeup.
- Debug and Release presets, grouped targets, installed CLI and external consumer tests.
- Unified task-result validation, shared task creation/polling budgets, and per-tool filtering of invalid HTTP header annotations.
- Public ownership/concurrency contracts, source provenance and official SDK interop fixtures.

This release starts a new public Git history. Attribution for earlier source development remains in `PROVENANCE.md` and `NOTICE`.
